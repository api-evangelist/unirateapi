# UniRate API

> Free and Pro currency exchange-rate, currency-conversion, VAT, historical, and commodities
> API over a simple REST interface. Current-rate endpoints are free (self-serve key, no card);
> historical and commodities endpoints require a Pro subscription. 170+ fiat currencies,
> 500+ cryptocurrencies, and country VAT rates. Authentication is an `api_key` query parameter.

Generated by API Evangelist (https://apievangelist.com) from the provider's public OpenAPI and
docs on 2026-09-16. This is a third-party profile, not a provider-published llms.txt.

## Base URL

- Production: https://api.unirateapi.com
- Every request must send `Accept: application/json` and include `?api_key=YOUR_KEY`.
- Get a free key at https://unirateapi.com.

## Operations (free tier)

- getRates — GET /api/rates — current rate for a `to` currency, or all rates for `from` base.
- convert — GET /api/convert — convert `amount` from one currency to another at the current rate.
- getCurrencies — GET /api/currencies — list of supported ISO 4217 currency codes.
- getVatRates — GET /api/vat/rates — VAT rates for all countries, or one `country`.

## Operations (Pro tier, HTTP 403 on free)

- getHistoricalRates — GET /api/historical/rates — rate on a specific `date` (coverage from 1999).
- getTimeSeries — GET /api/historical/timeseries — daily rates across a date range (max 5-year span).
- getHistoricalLimits — GET /api/historical/limits — per-currency historical coverage window.
- Commodities (live Swagger 2.0 only): /api/commodities/symbols, /rates, /convert,
  /historical/rates, /historical/timeseries — precious metals + 19 commodities.

## Conventions

- Rate/amount values are decimal STRINGS ("0.92") — parse to a decimal/float.
- Optional `format` query param: json (default), xml, csv, tsv. Optional JSONP `callback`.
- Errors: flat JSON `{"error":"..."}` (NOT RFC 9457). 400/401/403/404/429/503.
- Rate limits per key, reset midnight UTC; 429 on exhaustion; no RateLimit-* headers documented.
